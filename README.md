# Hola, soy Framber Silva (@frambersilva) 👋

## 🚀 Desarrollador Web | Astro • JavaScript • WordPress • Blogger

Soy un desarrollador y diseñador web especializado en crear experiencias digitales rápidas, escalables y optimizadas para motores de búsqueda (SEO). Mi enfoque principal es la construcción de interfaces modernas y de alto rendimiento con **Astro** y **JavaScript**, junto con el desarrollo de soluciones a medida, plugins y plataformas e-commerce en **WordPress** y **Blogger**. Combino el rendimiento técnico con un diseño frontend sólido para maximizar la visibilidad y retención de usuarios.

### 🛠️ Tecnologías y Herramientas

*   **Frontend:** Astro, JavaScript, HTML5, CSS3, animaciones UI (Glassmorphism).
*   **CMS y E-commerce:** WordPress (WooCommerce, desarrollo de plugins personalizados), Blogger.
*   **Diseño Web:** Framer, Divi 5.0.
*   **Otras Tecnologías:** Integración de APIs REST, SEO Técnico, desarrollo móvil híbrido (Flutter).
